# Advanced Tic-Tac-Toe

Ultimate tic-tac-toe in the browser: nine tic-tac-toe boards in one, Red vs Blue.

- Play a friend on the same screen, or the computer (easy, medium, hard).
- Where you play decides which board your opponent must play in next.
- Win three small boards in a row to win the game.

Play it: https://zipprelite.github.io/advanced-tic-tac-toe/
